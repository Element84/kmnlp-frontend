# 04 Chat Collapsed Map Maximized

## Overview
Shows the application with the chat view completely collapsed to a minimal strip, maximizing screen space for the map view while preserving access to all three main components.

## Layout Changes

### Three Main Components (Chat Collapsed State)

#### 1. Chat Management Controls (Minimized)
- **State**: Still accessible but in compact form
- **Position**: Top-left corner in the collapsed chat strip
- **Visibility**: Chat management and "New Chat" buttons likely still available

#### 2. Chat View (Collapsed)
- **Width**: Reduced to minimal strip (~40-50px wide)
- **Visible Elements**: Only essential navigation icons and controls remain
- **Background**: Light gray/white maintained
- **State**: Fully minimized but expandable
- **Functionality**: Core chat access preserved in compact form

#### 3. Map View (Maximized)
- **Width**: Approximately 95-98% of viewport
- **Enhanced Coverage**: Full geographic view of Gulf Coast region
- **Detail Level**: More geographic area visible (Louisiana, Mississippi, Alabama, Florida coastline)
- **Active Elements**: Blue polygon selection preserved in Gulf of Mexico
- **Controls**: All map controls remain accessible on right side

### Map Controls
- **Same Position**: All map controls remain on right side
- **Same Functionality**: Zoom, search, layer controls unchanged
- **Bottom Toggle**: Data Visualization Legend still available

## User Experience
- **Focus Mode**: Maximum attention on geographic data
- **Responsive Design**: Effective space utilization
- **Quick Access**: Chat can likely be restored via expand control
- **Unobstructed View**: Clear view of spatial data and relationships

## Visual Hierarchy
- **Map Primary**: Geographic content becomes dominant
- **Controls Secondary**: Navigation controls remain accessible
- **Branding Maintained**: NOAA identity preserved in minimal form

## Key Features
- **Space Optimization**: Maximum screen real estate for map
- **Maintained Functionality**: All core map features remain accessible  
- **Reversible Action**: Design suggests chat panel can be restored
- **Geographic Focus**: Enhanced view for spatial analysis tasks
- **Selected Context**: Previous area selection preserved
