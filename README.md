# Front-End

React-based web interface for the KMNLP project, built with TypeScript, Vite, and the US Web Design System.

## Quick Start

### Install dependencies
``` bash
yarn
```

### Run development server
``` bash
yarn dev
```

### Run tests
``` bash
yarn test
```

### Run Storybook
``` bash
yarn storybook
```

### Build

```bash
yarn build
```
